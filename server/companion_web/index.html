      Google Maps API key

      The map works without a key. With your own Google Maps key, Google's map is one more base map: paste the key here.

      1. In Google Cloud, enable the Maps JavaScript API and create an API key.
      2. Restrict the key: API restriction Maps JavaScript API; application restriction Websites:
      3. Paste it here.

      In Google Cloud, add to the key's Websites restrictions: the phone opens the map at another address than the PC.

      A key is stored.

      Live map on your phone

      Scan the code with the phone's camera: it opens this map in the phone's browser (nothing to install).

      • The phone must be on the same Wi-Fi / network as this PC.
      • Windows may ask to allow the world server through the firewall the first time: allow it on private networks. A network set to Public blocks phones.
      • The link is plain HTTP on your own network: use it at home, not on public Wi-Fi.
      • Your Google Maps key: add to its website restrictions too.
